# TagMyAudio

Free and open-source audio tag editor and converter for macOS and Windows.

## Download version 1.8.6

[Download applications and complete build kits](https://github.com/TagMyAudio/TagMyAudio/releases/tag/v1.8.6).

- macOS: Apple Silicon (arm64) and Intel (x86_64).
- Windows 10 / 11: Setup installer and standalone portable EXE.
- These distributions were reported tested by the maintainer on Windows 10/11, Mac Intel and Apple Silicon.
- Verify your download against `SHA256SUMS.txt` in the release.

![TagMyAudio application](https://raw.githubusercontent.com/TagMyAudio/TagMyAudio-Website/main/assets/application.png)

## Features

Edit track and album tags, rename tracks, find and add artwork, group albums while preserving track order, listen while editing, and convert audio to MP3, FLAC, WAV, AAC, ALAC, Ogg Vorbis or Opus. CUE albums can be split into individual audio tracks. Interface zoom ranges from 70% to 150%.

## Sources and building

Application code, all twelve translations, tests, fixtures, icons, build scripts and dependency notices are tracked here. Large bundled tools and upstream source archives are distributed in the full Sources and platform Build ZIPs in Releases, not in Git history.

For a complete offline build, use the platform build kit from Releases. Read [BUILD-macOS.md](https://github.com/TagMyAudio/TagMyAudio/blob/main/BUILD-macOS.md), [BUILD-WINDOWS.md](https://github.com/TagMyAudio/TagMyAudio/blob/main/BUILD-WINDOWS.md) and [BUILD-NOTES.md](https://github.com/TagMyAudio/TagMyAudio/blob/main/BUILD-NOTES.md). The Git checkout alone is not a complete offline build kit.
